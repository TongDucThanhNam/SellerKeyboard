## Current implementation observed

- InputMethodService hosts a Compose input view.
- Local deterministic Telex, clipboard repository/classification, voice controller, inline autofill controller, settings storage, general calculator, snippets, and image-commit primitives exist.
- Editor policy currently recognizes common password, email, URI, and numeric classes, but sensitivity and action/layout coverage are incomplete.
- Delete currently requests UTF-16-unit deletion rather than code-point/grapheme-safe deletion.
- Enter currently sends key events rather than resolving `imeOptions` and multiline policy.
- Durable session state and feature arbitration are distributed rather than coordinated centrally.
